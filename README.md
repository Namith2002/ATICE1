### Adding an IOC (Indicator of Compromise)
1. Go to "Ingest IOC" page
2. Fill in the form:
   - Type: CVE
   - Value: CVE-2024-1234
   - Source: virustotal
   - Confidence: 0.8

4. View it in "All IOCs" page

### Generating a Report

### Backend won't start
```powershell
pip install -r backend/requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Frontend won't load
- Ensure backend is running on port 8000
- Clear browser cache (Ctrl+Shift+Del)
- Hard refresh (Ctrl+Shift+R)

### Login fails
- Use credentials: admin/admin
- Check browser console (F12)
